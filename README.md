# SajjadPortfolio

Personal portfolio of **Sajjad Ali**, IT / System Administrator and Technical Support Specialist based in Lahore, Pakistan.

Built with plain HTML, CSS and JavaScript. No build step is needed.

## Run locally

Open `index.html` in a browser.

## Deploy

- **GitHub Pages:** Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
- **Netlify:** drag the folder into Netlify, or connect this repository.
